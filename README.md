# Qubitrino — WebGL-прототип главного экрана

**Живая версия: https://maletskiy.github.io/qubitrino-webgl/**

Живой прототип первого экрана лендинга Qubitrino: знак собран из ~5200 частиц
с глубиной, bloom и боке, реагирует на курсор, раскручивается в спираль по скроллу
и уступает место второму блоку.

## Что посмотреть

1. **Прелоадер** — кубит в суперпозиции, две кнопки входа: со звуком и без.
2. **Знак** — двигайте мышью: сцена наклоняется, точка резкости следует за курсором,
   рядом с курсором загорается свечение.
3. **Скролл** — знак раскручивается, нижний блок доезжает до центра, гаснет и уходит
   вверх, снизу поднимается светлая карточка.
4. **Эквалайзер** справа в шапке — включает и выключает музыку.

## Как это сделано

- WebGL2 без библиотек: частицы → HDR-таргет, bright-pass, два уровня гауссова
  размытия, композит с тонмаппингом, виньеткой и зерном.
- Глубина резкости честная: у каждой частицы своя circle-of-confusion, поэтому
  дальние точки превращаются в мягкие кружки, а не «размывается картинка».
- Звук: трек обрезан до 46 секунд с фейдами, эквалайзер — на AnalyserNode.
- Кастомный курсор на `mix-blend-mode: difference` — виден и на тёмном, и на светлом.

## Локальный запуск

```bash
python3 -m http.server 8000
# открыть http://127.0.0.1:8000
```

Через сервер эквалайзер показывает настоящий спектр; при открытии файла с диска
(`file://`) звук играет, но эквалайзер переходит на процедурную волну — Chrome
не отдаёт данные анализатора для локальных медиа.
